# xu30-strateji-arastirma
XU30 strateji araştırma ajanının çalışma deposu. Ajan her ~3 saatte bir `AJAN.md`'yi okuyarak koşar.
- `motor.py` — sabit test motoru (ajan değiştirmez)
- `xu30_kesif_m1_gunduz.csv.gz` — keşif verisi (624 seans, ≤ 08.09.2026). Kilitli 20 seans burada YOK.
- `defter.csv`, `durum.json` — tüm denemeler ve keşif sayacı (KS)
- `kartlar/`, `sinyaller/`, `kosular/`, `raporlar/`, `adaylar/`
- `VIDEO_AJANI.md` — video alt ajanı talimatı (ana ajan adım 3b'de başlatır); `videolar/gelen/` transkript gelen kutusu, `video_gunlugu.csv`
- `havuz.csv`, `arama_rehberi.md`, `arama_gunlugu.csv` — fikir havuzu ve arama kaynakları
